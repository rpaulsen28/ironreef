# About page photos

Upload photos into this folder with these exact names and they appear on the About page automatically:

| File name | Where it shows | Best shape |
|---|---|---|
| `portrait.jpg` | Top of the page, next to the intro | Tall (portrait), like 4:5 |
| `diving.jpg` | Beside "Below the surface" | Tall, like 2:3 |
| `rodeo.jpg` | Beside "In the arena" | Tall, like 4:5 |

Until a photo is uploaded, its spot stays hidden, so the page always looks finished.
Phone photos are fine; keep each under about 1 MB if you can so the page loads quickly.
